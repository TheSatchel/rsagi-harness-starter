# 玩家感知与不完全信息

本规则记录已经确定的感知边界，正式客户端参数与验收要求仍需赛前发布。

## 可用信息

模型只能通过绑定角色的真实第一人称画面、当前可见的游戏界面及正常混音后的游戏声音取得世界信息。赛前公开规则、任务和轮次/配额控制信息可以同样提供。

**允许原版 F3。** 各队使用统一设置，通过规定输入打开/关闭 F3，在对应轮末读取画面实际显示的坐标、朝向和调试内容；不另行注入后台数值或提供结构化导出。

角色需要实际移动、转身、走近、开箱或翻页，才能取得相应新信息。每轮五 tick 执行完成、客户端应用状态后才发布新观察；等待模型期间复用已发布边界，不免费刷新或额外扫描。

## 不提供的信息

- 服务端存档、种子、要塞/入口坐标清单、地下矿物或未打开箱子的内容；
- 其他队伍的位置、装备、血量、背包、模型日志或私有观察；
- 已加载但未实际渲染的方块/实体、原始客户端数据包、旁观/俯视真值；
- 主办方 OCR、音效语义注释、目标识别、地图总结或导航建议；
- 管理员调试接口、原始控制台或越权游戏指令。

声音中的方位和游戏画面中的线索由模型自己理解。收到数据包不代表人类玩家已经看见；后台事实改写成自然语言也不符合要求。

## 上下文与运行中变化

允许模型记忆和推理合法观察。主办方管理原始观察与模型原始输出，不用 RAG、外部语义笔记、摘要或静默删截补齐信息。上下文达到限制时停止，不自动扩展记忆。

运行中自组织或源码变化不得把地图事实编码到外部常量、配置或注释中。Starter 只演示有来源的角色/预算配置修订；对任意代码的语义存储审计和隔离尚未实现。

分辨率、FOV、视距、亮度、资源包、GUI、字幕和音频等设置需要统一固定。F3 的许可不意味着额外模组、调试工具或免费观察通道也被允许。

机器可读约束见 [perception-policy.json](../config/perception-policy.json)。当前可信捕获端未接入；Mock 数据不可作为真实感知或正式比赛验收证据。
